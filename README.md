# SessionPulse — Чекер и сортировщик пар `.session + .json` для Telegram

Лёгкая асинхронная консольная утилита на Python (`Telethon` + `rich`) для массовой проверки и сортировки аккаунтов Telegram в формате `.session` и `.session + .json`.

## Возможности
- **Авточтение `.json` метаданных:** подхватывает `app_id`, `app_hash`, `device`, `sdk`, `app_version`, `lang_code` и пароль `twoFA` из JSON-файла рядом с сессией (если `.json` отсутствует — использует стандартные параметры).
- **Поддержка прокси:** HTTP, SOCKS4 и SOCKS5 (`protocol://user:pass@ip:port` или `ip:port:user:pass`). Битые прокси отсеиваются в отдельную папку `proxy_error`, не записывая живые аккаунты в мёртвые.
- **Проверка через `@SpamBot`:** определяет чистые аккаунты, временный спамблок (с извлечением даты окончания), вечный спамблок и заморозку.
- **Сбор информации:** номер телефона, `user_id`, `@username`, номер дата-центра (`DC`), статус `Telegram Premium`, наличие `2FA`.
- **Автосортировка и отчёт:** раскладывает пары `.session + .json` по папкам и формирует подробный CSV-отчёт для Excel.

## Запуск
1. Положите файлы `.session` (и `.json`) в папку `sessions/`.
2. При необходимости добавьте прокси в `proxies.txt`.
3. На Windows запустите `start.bat` (или выполните `pip install -r requirements.txt && python main.py`).
